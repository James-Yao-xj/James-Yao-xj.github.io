第三章 第七讲：数组、结构体与浮点指令

来源：ICS07，2026 年 9 月 28 日，51 页。

2. 结构体、偏移与对齐

成员依声明次序排列，编译器在成员之间及末尾插入填充。设当前偏移为 、成员要求按 对齐，则成员偏移为

结构体整体对齐要求等于成员对齐要求的最大值，最终大小也向该值的整数倍取整。这保证结构体数组中每个元素都满足对齐要求。

课件的 struct S1 { char c; int i[2]; double v; }：c 偏移 0，i 偏移 4，v 偏移 16，整体 24 字节。struct { char c; int i; char d; } 占 12 字节；改为 int i; char c; char d; 占 8 字节。

结构体数组寻址遵循：数组首地址 + 下标 × 结构体大小 + 成员偏移。short, float, short 的例子中，整体大小 12，末成员偏移 8。

链表访问是反复读取 next 成员所在地址的指针值；成员偏移是编译期常量，结点地址在运行时变化。

2.1. 对齐如何在字段之间插入空隙

取 struct S { char c; int x; short y; };，采用 char、int、short 的大小与对齐分别为 1、4、2 的布局。c 放在偏移 0，占一字节；x 要从 4 的倍数处开始，所以偏移 1 到 3 留空，x 放在偏移 4 到 7；y 接在偏移 8、9。

结构体整体对齐要求为最大字段对齐 4，总大小需为 4 的倍数，因此末尾偏移 10、11 也补齐，总大小为 12。这样数组 S a[2] 中第二项从偏移 12 开始，其 x 字段位于偏移 16，仍保持四字节对齐。

若只把字段大小相加得到 7，会同时算错 sizeof、数组步长和后一元素的字段地址。计算时应按声明顺序逐字段“向上对齐—放入字段”，最后再对整个对象补齐；填充字节没有独立成员名，但确实占据对象的存储空间。

3. 浮点数的机器级操作

XMM 寄存器为 128 位，可用于标量或 SIMD 运算。ss 表示标量单精度，sd 表示标量双精度；ps、pd 表示打包单精度、双精度。

System V AMD64 调用约定中，浮点参数依次使用 %xmm0 至 %xmm7，浮点结果放在 %xmm0，XMM 寄存器由调用者保存。整数、指针与浮点参数分别使用各自的参数寄存器序列。

movss/movsd 传送，addss/addsd 做加法。ucomiss/ucomisd 比较后设置 ZF、PF、CF：大于为 000，小于为 001，等于为 100，含 NaN 的无序比较为 111。因此无序不能直接按普通相等处理。

4. 指针表达式与声明

*p++ 取旧地址的值，再移动指针；(*p)++ 修改指向的元素；*++p 先移动再读取。 int *p[3] 是指针数组，int (*p)[3] 是指向三元素数组的指针。读声明时先处理标识符附近的括号与方括号，再处理指针。

9. 课堂例题：浮点参数与比较

第 38—42 页。 XMM 寄存器宽 128 位，可以容纳四个 float 或两个 double；addss 只计算低端一个 float，addps 同时计算四个 float，addsd 计算低端一个 double。

double dincr(double *p,double v) 中 p 走 %rdi，v 走 %xmm0，两类参数分别分配寄存器。课件代码先将 v 备份到 %xmm1，再把 *p 读到 %xmm0；用 %xmm1 求新值、写回内存，而 %xmm0 保留旧值作为函数返回值。

ucomiss/ucomisd 更新 ZF、PF、CF：无序（含 NaN）为 111，大于为 000，小于为 001，相等为 100。比较逻辑先检查无序情形，才能区分普通相等与 NaN。

10. 附加页课堂表：指针声明的逐层展开

第 45—51 页，64 位环境。 sizeof 按当前表达式类型计算；解引用先去掉一层指针或数组，不会自动变成最终 int：

声明An*An**An***An
int A1[3]124不合法不合法
int *A2[3]2484不合法
int (*A3)[3]8124不合法
int A1[3][5]60204不合法
int *A2[3][5]1204084
int (*A3)[3][5]860204
int (*A5[3])[5]248204

例如 int (*A3)[3][5] 是“指向 3×5 int 数组的指针”：自身 8 字节，一次解引用得到 60 字节数组，再解引用得到 20 字节一行，再解引用才是 4 字节 int。数组内若保存未赋值的指针，真正读取其所指对象时还涉及指针有效性；sizeof 的类型计算与实际读取对象是两件事。

11. 补充例：指针加一的三种步长

对 int A[2][3]，假定 int 占 4 字节：A+1 跨过一行，增加 12 字节；&A+1 跨过整个二维数组，增加 24 字节；A[0]+1 跨过一个元素，增加 4 字节。它们起始地址的数值相同，指向的类型不同，因而缩放不同。

函数形参写成 int a[10] 时，实际调整为指针形参。函数内 sizeof(a) 得到指针大小，不能恢复调用者数组长度；而调用者直接对实际数组取 sizeof，得到的是整个数组字节数。长度应由接口参数或已知维数提供。

混合参数也有两套寄存器计数。例如 f(int *p,double x,long n,double y) 中，p、n 分别使用 RDI、RSI，x、y 分别使用 XMM0、XMM1；浮点参数不占掉整数寄存器序列的位置。
