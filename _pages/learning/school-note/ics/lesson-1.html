3. 系统视角的五个例子

来源：ICS01 的课程主体部分。

有限位宽整数与实数算术不同：补码机器加法保留低位，而 C 的有符号溢出不具有普通整数代数的语言保证。浮点运算还会舍入，结合次序能够改变结果。

汇编揭示类型转换、访存和控制流。sizeof 的类型为无符号 size_t，与负的有符号数混合比较时，通常算术转换会改变比较含义。转换取决于双方的类型等级和可表示范围。

内存错误具有位置效应：同一越界写可能先改邻近字段，再改控制信息。性能也有位置效应：按行连续扫描二维数组通常比按列大跨度访问更容易利用局部性。

指针别名改变程序语义。连续两次 *x += *y，当 x==y 时最终为原值四倍；一次 *x += 2*(*y) 则为三倍，二者不能直接替换。

输入输出和并发是程序执行模型的一部分：两个操作都先读库存 100，一个加 50，一个减 40，再分别写回，可能丢失其中一次更新。正确的顺序结果应为 110。

机器位运算的结果与无限精度整数的平方不同。在 C 源程序中分析有符号溢出，还要结合语言规则与编译优化；机器低位结果不能作为所有 C 表达式的统一保证。

4.2. 例 1.2：浮点加法的括号（第 18—20 页）

(1e20 + -1e20) + 3.14 先把两个大数抵消，保留结果约 3.14；1e20 + (-1e20 + 3.14) 的内层先加一个相对极小的数，3.14 落在大数的有效精度之外，舍入后仍约为 −1e20，再相加得 0。

因此浮点求和的每个括号都规定了一次中间舍入。课件例 1.3 使用 fabs(a-b)<=epsilon 比较近似值，如给定绝对容差 0.00001；当数值量级变化很大时，容差的含义也需按问题的误差尺度确定。

4.3. 例 2.1：负数与 sizeof 比较（第 21 页）

int array[] = {1, 2, 3};
#define TOTAL sizeof(array)
int d = -1;
if (d <= TOTAL) printf("small\n");
else printf("large\n");

在课件常用的 64 位环境中，TOTAL 为 12，类型为无符号 size_t。比较先将 −1 转成相应无符号值，成为非常大的正数，条件为假，输出 large。sizeof(array) 计字节数；若要元素数，则应取 sizeof(array)/sizeof(array[0])。

    *x += *y;
    *x += *y;

4.5. 例 2.3、2.4：周期计数器与字符串输入（第 23—24 页）

rdtsc 将计数器的低 32 位放在 EAX，高 32 位放在 EDX；组合成 64 位值需先扩展高半部，再左移 32 位并合并低半部。它说明某些硬件状态需要汇编接口访问。

gets(buf) 的接口没有缓冲区容量，输入长度超过数组就可能覆盖后续内存；课件对照 fgets(buf,BUFSIZE,stdin)，后者最多写入容量内的字符并补终止符。分析此类反汇编时，需要同时看数组大小、栈帧分配和传给库函数的参数。

4.6. 内存越界例：相邻 int 与 double（第 25—27 页）

结构体先有 int a[2]，随后有 double d，先赋 d=3.14，再写 a[i]=1073741824。常见布局下 a 占偏移 0—7，d 占 8—15；a[2] 写到 d 的低四字节，a[3] 写到高四字节。这解释课件中前两次仍输出 3.14，后续出现约 3.1399998665、2.0000006104 的现象。更远的越界可能破坏栈中的其他状态。

4.7. 访存顺序例：2048×2048 数组（第 30 页）

两个复制程序均执行 次元素赋值。copyij 的内层遍历 j，连续地址相差 4 字节；copyji 的内层遍历 i，连续两次访问相差 字节。课件测试在其给定 Haswell 机器上约为 4.3ms 与 81.8ms。

相同的 运算次数下，缓存行利用、预取和地址转换行为不同，导致实际耗时差约 倍。

4.8. 例 5.1：库存更新丢失（第 33 页）

两名业务员都读取 100：入库者计算 150，出库者计算 60。先写 150、后写 60，最终为 60；反过来则为 150。按任意一种完整的串行执行，正确结果都是 。

错误来自读、修改、写三个步骤交错，而非加减法计算本身；用互斥或具有相同语义的原子更新，才能让一次业务操作在并发中保持完整。

5. 补充例：从一次数组访问连接各层概念

设 int a[3]={10,20,30}; int x=a[2];，a 的数值首址为 0x1000，int 为 4 字节。编译器把下标 2 缩放为 8，因此读取地址 0x1008 的 4 字节。小端机器上它们为 1e 00 00 00，拼成整数 30。

源程序的类型决定读取宽度和缩放比例；指令指定有效地址；处理器通过存储层次取得字节。若这些字节已在缓存中，访问可直接命中；否则还需向下层请求。改变存储位置会影响用时，按程序语义读取到的元素仍是 30。这把“程序如何表示数据”和“程序为何快慢不同”连接到同一个例子。
