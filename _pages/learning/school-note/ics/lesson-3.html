3.2.5. NaN

规则：指数域全 1 且小数域非零。NaN 分为 quiet NaN（qNaN）和 signaling NaN（sNaN）；具体如何用 frac 的最高位区分由格式约定。NaN 的其余小数位可作为 payload 保存诊断信息，但跨运算、语言或平台时不应假定 payload 必然保留。

NaN 的比较规则很重要：除“不等于”外，普通有序比较都返回假。因此若 x 为 NaN，则 x == x 也为假，x < 0 与 x >= 0 同样都为假。检查 NaN 应使用语言提供的 isnan，而不是依赖大小比较。

3.6.3. 融合乘加（FMA）

fma(a, b, c) 计算 ，只在最终结果处舍入一次；普通写法 a*b+c 允许乘法结果先舍入，再进行加法。

例： 若 的精确值含有目标格式无法保存的低位，而这些低位会与 发生抵消，则 FMA 能在相加前保留它们，可能得到比两次舍入更准确、甚至不同的结果。因此编译器把 a*b+c 改成 FMA 会改变逐位结果，严格浮点语义下需要相应许可。

3.7. 比较、次序与代数性质

  • 除 NaN 外，有限数和无穷可按数值有序比较； 与 数值相等。
  • 任一 NaN 参与 <、<=、>、>=、== 时结果均为假；!= 为真。
  • IEEE 754 还定义 totalOrder，可以对 、、无穷和不同 NaN 表示建立全序；它不同于普通语言比较运算符。
  • 加法和乘法通常是交换的，但不结合；乘法不对加法分配。
  • 有限浮点运算不对实数运算封闭，因为结果可能为无穷或 NaN。

例： 若 x 为 NaN，条件 x < 1 || x >= 1 为假，而实数中对应命题恒真。这是因为 NaN 是 unordered，而不是“小于”或“大于”任何数。

4. C 中的浮点数

4.1. 类型与表达式

C 语言至少提供 float、double 和 long double，但语言标准本身不要求它们必须分别等同于 IEEE binary32、binary64 与某一固定扩展格式；应通过实现文档、sizeof、FLT_RADIX、FLT_MANT_DIG、DBL_MANT_DIG 等确认。

没有后缀的浮点常量如 0.1 通常具有 double 类型，0.1f 才是 float。许多表达式中 float 会经通常算术转换参与运算；可观察的求值精度还受实现、编译选项和是否使用 FMA 影响。

4.2. 类型转换规则与例子

4.2.1. 整数转浮点

若值可精确表示，则结果精确；否则舍入为相邻可表示值。binary32 具有 24 位精度，所以所有绝对值不超过 的整数都能精确表示，但更大的整数不一定能。

例： 16777216（）能精确转为 binary32；16777217 夹在相邻可表示值之间，正中取偶时转为 16777216.0f；16777218 可以精确表示。

典型 32 位 int 的所有值都可精确转为 binary64，因为 binary64 有 53 位精度。

4.2.2. 浮点转整数

C 的转换丢弃小数部分，即向零截断。若有限值截断后不能在目标整数类型中表示，或源值是 NaN/无穷，则行为未定义；不能依赖某台机器恰好返回的值。

例： (int)3.9 得 ，(int)-3.9 得 。但 (int)1e100 或 (int)NAN 没有可移植结果。

4.2.3. 不同浮点格式之间

从较窄格式转到能精确包含其全部值的较宽格式通常精确；从较宽格式转到较窄格式可能舍入、上溢或下溢。

例： binary32 值先转 binary64 再转回 binary32，数值不变（NaN payload 等表示细节除外）。binary64 的 1.0 + 2^-30 转为 binary32 时会舍入为 1.0f，因为该增量远小于 binary32 在 1 附近的间距 。

4.3. 位模式解码的可靠做法

在 C 中不要用违反严格别名规则的指针强制转换读取浮点位模式。可使用 memcpy（C20 以前的通用做法）或实现提供的位转换工具。

4.4. 常见判断题

设 int x; float f; double d;，并假设 f、d 不是 NaN；在常见的 32 位 int、binary32 float、binary64 double 环境中：

  • x == (int)(float)x：不恒真。例：，转 float 后成为 。
  • x == (int)(double)x：恒真，因为 binary64 能精确表示所有 32 位整数。
  • f == (float)(double)f：对所有非 NaN float 恒真，扩大再缩回不会丢失原值。
  • d == (double)(float)d：不恒真，第一次转换可能丢失 binary64 的低位。
  • f == -(-f)：对非 NaN 值恒真；两个负号也正确恢复有符号零。
  • 2/3 == 2/3.0：通常为假。左侧是整数除法，结果为 ；右侧为浮点除法，约为 。
  • d*d >= 0.0：在 d 不是 NaN 的前提下恒真。有限 d 的平方为非负有限数、正零或上溢后的正无穷；无穷的平方仍为正无穷。
  • (d+f)-d == f：不恒真。若 很大，加入较小的 时 会在第一次舍入中丢失。

4.5. 总结

  • 位模式必须先按 exp 与 frac 分类，再使用对应公式；规格化数和次正规数的隐含首位、指数规则不同。
  • IEEE 754 明确定义特殊值、舍入方向、默认结果与异常标志，使浮点行为可以独立于具体硬件进行推理。
  • 浮点运算相当于精确运算后舍入，但有限精度会破坏结合律与分配律。
  • 数值范围、有效精度和相邻数间距是不同概念；误差分析必须考虑数值所在的指数区间。
  • C 的类型不应未经确认就等同于某个 IEEE 格式，转换越界、NaN 比较和近似相等判断尤其需要显式处理。
