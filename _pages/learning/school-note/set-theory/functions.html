1.1. 把定义写成一张输入输出表

取 、，依次为三个输入选输出。全函数可记为三格表，例如 (a,b,a) 表示 1→a、2→b、3→a；每格有两个选择，共八张表。多个输入共用 a 不妨碍成为函数，因为检查的是同一输入是否出现两个不同输出。

若改为偏函数，每格还可写“未定义”，因而有三种选择，共 27 张表。空关系也是偏函数，对应三格全未定义；但在非空 A 上它不是全函数。若 A 为空，则根本没有格子，恰有一张空表，解释了空定义域上函数的唯一性。

满射要求 a、b 都出现，所以从八张全函数表中删去 (a,a,a) 与 (b,b,b)，剩六张。单射则要求三格输出各不相同，两个候选值装不下三个不同输入，故不存在。这一步把定义域大小、陪域大小和鸽巢原理联系起来。
