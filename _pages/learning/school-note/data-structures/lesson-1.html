1.1. 问题描述：股市传言

若干股票经纪人之间互相传消息。谁能直接传给谁、要花多久，都是已知的。

问：从哪一个人开始散布消息，能让所有人最快都知道？（也就是最后知道消息的人今早得知）

解法拆分为三步：

  • Floyd:先算出任意两人之间的最短传播时间；
  • 每行取最大：消息要传遍所有人，就得等最慢的那个人收到
  • 各行的最大值里取最小：这个起点就是答案
  • 某一行还留着，有人永远收不到，这个起点不合格。

2. 代码实现

这里的逻辑很容易理解，那么，如何实现Floyd算法呢？我们可以用一个二维数组来表示每个人之间的传播时间，初始化时，如果两个人之间有直接的传递关系，就将对应的数组元素设为该传递时间，否则设为无穷大（表示无法直接传递）。然后，我们通过三重循环来更新这个二维数组，逐步计算出任意两人之间的最短传播时间。

对应的 C++ 三重循环如下：

for (int k = 1; k <= n; ++k) {
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= n; ++j) {
            dist[i][j] = min(
                dist[i][j],
                dist[i][k] + dist[k][j]
            );
        }
    }
}

三个循环变量分别表示：

  • ：本轮允许经过的中间点；
  • ：路径的起点；
  • ：路径的终点。

2.1.3. 初始化距离数组

首先，将所有节点之间的距离初始化为无穷大，并将节点到自身的距离设为 ：

const long long INF = 4e18;

vector<vector<long long>> dist(
    n + 1,
    vector<long long>(n + 1, INF)
);

for (int i = 1; i <= n; ++i) {
    dist[i][i] = 0;
}

读入一条从 from 到 to、传播时间为 time 的有向边：

int from, to;
long long time;

cin >> from >> to >> time;

dist[from][to] = min(dist[from][to], time);

这里使用 min，是为了处理两个节点之间可能存在多条直接路径的情况。

如果题目中的关系是双向的，还需要添加：

dist[to][from] = min(dist[to][from], time);

2.1.4. 防止无穷大参与加法

如果 无法到达 ，或者 无法到达 ，那么就不存在路径：

因此可以直接跳过本次计算：

for (int k = 1; k <= n; ++k) {
    for (int i = 1; i <= n; ++i) {
        if (dist[i][k] == INF) {
            continue;
        }

        for (int j = 1; j <= n; ++j) {
            if (dist[k][j] == INF) {
                continue;
            }

            dist[i][j] = min(
                dist[i][j],
                dist[i][k] + dist[k][j]
            );
        }
    }
}

这样既能减少无效计算，也可以避免无穷大相加导致整数溢出。

对应的 C++ 代码如下：

int answer = -1;
long long bestTime = INF;

for (int i = 1; i <= n; ++i) {
    long long lastArrival = 0;
    bool reachable = true;

    for (int j = 1; j <= n; ++j) {
        if (dist[i][j] == INF) {
            reachable = false;
            break;
        }

        lastArrival = max(lastArrival, dist[i][j]);
    }

    if (reachable && lastArrival < bestTime) {
        bestTime = lastArrival;
        answer = i;
    }
}

如果 answer == -1，说明不存在一个能够把消息传给所有人的起点：

if (answer == -1) {
    cout << "disjoint\n";
} else {
    cout << answer << ' ' << bestTime << '\n';
}

4. 补充例：循环顺序为什么会影响答案

取四个顶点，仅有有向边 、、，边权均为 1。正确最短路 长为 3。若错误地按 i、j、k 各从小到大只循环一遍，在处理 i=1、j=2 时， 尚为无穷， 也尚为无穷，不能更新。随后处理 j=3 才经 4 得到 ，却不会回头重新处理 j=2，最终漏掉这条路。

把 k 放最外层，允许中间点 3 时先得到 ；允许中间点 4 时，得到 。这给出了破坏状态定义的实际后果，而不只是记忆三层循环的字母顺序。

4.1. 补充例：最短距离与总工作量

从某起点到三个接收者的最短到达时间分别为 2、5、7，若信息可以同时沿多条边传播，全部收到的时刻是 7，不是 。求和适合“总距离”目标，最大值适合“最后完成时间”目标。建模时先把题目问的量写出来，再选择矩阵行上的汇总方式。
