数据结构与算法 第四讲：字符串与 KMP

来源：第四章 String 课件（66 页）、配套 Markdown、KMP 比较次数模拟和 MOOC 第四章习题。

字符串匹配的关键是利用已经比较过的信息。朴素算法在失配后重新开始，KMP 则保存已匹配部分的边界，让主串指针持续向前。

1. 串、编码与存储

串是字符的有限序列，空串长度为 0，空白串含空格且长度非零。子串必须连续，子序列只要求保持相对次序。课件将非空且不等于原串的子串称为真子串。

ASCII 使用 7 位编码，数字、大写字母、小写字母分别连续。Unicode 给字符分配码点，UTF-8 以 1 至 4 字节编码码点。C++ char 是字节，std::string::size() 计编码单元；字节数、码点数与显示宽度分别是不同的量。

字典序看首个不同元素；若一串是另一串前缀，则较短者小。因此字符串 "123" < "1234" < "23"。字符串字面量之间直接用 < 会比较指针，比较内容应使用字符串对象或比较函数。

C 风格串以 \0 结束，char s[M] 最多容纳 字节内容。局部数组 char s[6]; 没有初始化，不能把它当作空串；char s[6] = {}; 才将首字节置零。

1.1. 子串的两种计数口径

aaa 有六个非空位置区间：三个长度 1、两个长度 2、一个长度 3；但不同内容只有 a、aa、aaa 三种。 来自选择区间的左右端点，未执行按内容去重。取 abc 时六个位置区间恰好各不相同，才同时得到六种内容。

2. String 类与变长管理

类保存缓冲区指针与长度，分配空间同时容纳终止符。构造分配，析构释放；拷贝构造和拷贝赋值复制字符本体，形成独立所有权。只复制指针会导致共享修改和重复释放。

赋值顺序是申请新空间、复制、释放旧空间、接管新指针。移动操作转移缓冲区的所有权。修改器返回 String& 可支持连续追加。

append 拼接，substr(start,count) 取连续区间，find 找首个位置，compare 返回大小关系。课件教学版每次按新长度重分配，追加一个字符为 ；按倍数扩容的实现才能使连续追加达到摊还 。

strlen 扫描到终止符，strcmp 按字典序比较，strchr/strrchr 分别定位首次和末次出现。数组赋值不等于复制内容。

3. 朴素模式匹配

主串 长 ，模式 长 ，均从下标 0 开始。令 为主串下标， 为模式下标：相等则同时加 1；失配则主串回到本趟起点后一位，模式回到 0。

匹配成功时主串下标已经越过匹配段，起点为 。课件指出原书返回式多加了 1。

最多检查 个起点，每趟至多 次比较，最坏 ；反例取主串全部为 a、模式为若干 a 后接 b。

3.1. 失配时为什么可以保留一部分匹配

模式为 ababaca。假设刚匹配好前五个字符 ababa，下一主串字符却是 b，而模式当前需要 c。把主串退回重比会浪费已知信息：已匹配片段末尾的 aba 同时是模式开头的 aba，所以它仍可作为新一轮的前三个已匹配字符。

此时已匹配长度从 5 退到 3，继续拿同一个主串字符 b 与模式下标 3 的 b 比较，即可扩展到长度 4。主串字符没有丢掉，也没有提前前进，改变的只是“已有多少字符仍可保留”的状态。

为什么不试长度 4？因为 ababa 的长度 4 后缀为 baba，不是模式前缀 abab，它在下一字符到来前就已不合格。失败链只枚举真正的边界，跳过这些已经确定不可能的长度。前缀函数存长度，某些 next 表存下标，读代码前把两者对应关系写清，再追踪赋值，就不会把同一整数解释成不同位置。

4. 普通 next、nextval 与前缀函数

本文统一记号：next[0]=-1，next[j] 是 的最长相等真前后缀长度。前缀函数 pi[j] 则针对 ，所以普通 next[j]=pi[j-1]。

失配时将 改为 next[j]，主串下标不动。已经匹配的后缀重新对齐模式的同长前缀。 若 P[j]==P[next[j]]，退到该位置还会与同一主串字符失配，可以继续沿失败链跳过，得到 nextval。

4.1. KMP 的匹配循环

i = 0; j = 0
while i < n and j < m:
    if j == -1 or T[i] == P[j]:
        i += 1; j += 1
    else:
        j = nextval[j]

成功条件为 ，返回 ；空模式匹配在位置 0。j==-1 是移动指针的分支，不执行字符比较，统计比较次数时不计入。

主串下标至多前进 次。模式下标的每次增加伴随主串前进，所有回退的总量受增加总量限制，所以匹配 ；预处理 ，总时间 ，额外空间 。

4.2. 比较次数例题

模式 BAAABBBAA，主串 BAAABBBCDDDCCHHHHBBBAAABBBAADD。用 nextval 在主串下标 19 首次成功，共 31 次比较：最初连续成功 7 次，C 处比较 2 次，下标 8 至 16 比较 9 次，下标 17 至 19 比较 5 次，最后 8 次成功。普通 next 在 C 处多比较一次，共 32 次。

4.3. 手工构造前缀函数

模式 ababaca 的前缀函数为 [0,0,1,2,3,0,1]。读到下标 4 的 a 时，前缀 ababa 的最长真边界为 aba，长度 3；下标 5 为 c，原本想把边界扩到 abab，但 c 与 b 不同。先沿失败链从 3 退到 pi[2]=1，仍与 b 不同，再退到 pi[0]=0，与 a 也不同，故该位置为零。下标 6 的 a 重新形成长度 1 的边界。

构造的基本步骤为：

// Return the longest proper border length for each prefix.
vector<int> prefix_function(const string& pattern) {
    vector<int> pi(pattern.size());
    for (int i = 1; i < static_cast<int>(pattern.size()); ++i) {
        int border = pi[i - 1];
        while (border > 0 && pattern[i] != pattern[border]) {
            border = pi[border - 1];
        }
        if (pattern[i] == pattern[border]) ++border;
        pi[i] = border;
    }
    return pi;
}

失败时只尝试更短的已有边界，因为任何可延长的候选前缀都必须先是前一段的后缀。每次 border 增加最多 1，回退总量不超过已增加总量，所以预处理是线性时间。

4.4. 从首次匹配继续寻找重叠匹配

在 aaaaa 中找 aaa，所有起点为 0、1、2。找到第一次后，已匹配后缀 aa 仍是模式前缀，应把已匹配长度退为 pi[2]=2，继续读下一个字符；若直接清零，会漏掉重叠结果。本文前面的返回语句用于“找第一次”，改为“找全部”时还需明确这一成功后的续接规则。

5. 最小周期与整串重复

令整串最长真边界长度为 ，则最小周期 。边界条件 与周期定义是同一组等式。

abcabcabc：，是 abc 的三次重复。 ababa：，周期 2 不整除长度 5，不能整串重复。 abcd：，没有更短重复单元。

非空串由更短串重复至少两次，当且仅当 且 被 整除。优化 nextval 跳过了部分边界，不能替代前缀函数求周期。

循环移位判定：两串等长，且第一串出现在第二串与自身连接的串中。连接可交换 时，非空的 是某一公共串的整数次重复。

6. 习题方法

  • 不同子串： 计的是按起止位置区分的非空子串，按内容去重后可能更少；字符互异时再加空串得到 。
  • 互补回文：依次比较首尾对应字符是否互补，再向中间推进。
  • 串表达式：逐层写出长度、索引、子串、替换、连接的中间值，统一下标起点。
  • 行编辑器：行结构管理插入删除，KMP 负责行内匹配；两种操作分别维护各自状态。

7. 课堂运行例：String 的四个操作

第四章课件第 4、18—32 页。 从 String text = "Hello" 开始，依次追加空格、C、+、+，得到 Hello C++，长度从 5 变成 9，缓冲区需有 10 字节以容纳结尾的 \0。

substr(6,3) 取下标 6、7、8，结果是 C++；find('C') 返回 6；append 返回当前对象的引用，所以前一次调用的结果仍能接着调用下一次。

教学版每次追加都重新申请长度加 2 的缓冲区，复制原字符，再写新字符和终止符。连续追加 次的复制量是 。如果另存容量并按倍数扩容，才可以把这一批操作的总复制量降为 。

复制对象时应得到两个独立缓冲区：String b=a 后改变 b 的某字符不影响 a。移动则接管原缓冲区，原对象转为空状态；“复制字符”与“转移拥有权”是课件三法则、移动构造示例的关键区别。

7.1. 标准串函数的结果类型

strchr(s,'a') 返回首个匹配字符的地址，strrchr 返回最后一个；位置可通过返回指针减去 s 得到。strcmp 返回负、零、正，约定只依赖符号；不能把返回值必为 −1、0、1 当作接口要求。

对 char s[]="abc"，sizeof(s)=4 而 strlen(s)=3；对指针 const char* p="abc"，在课件的 64 位环境中 sizeof(p)=8。s1=s2 不能实现数组字符内容复制。

9. 课堂例题：两种模式的 next 与逐步匹配

9.1. abcdaabcab 的失败表（课件第 50—51 页）

下标 4 前面的 abcd 没有非空真边界，普通值为 0；但 P[4]=P[0]='a'，若当前位置与主串失配，退回 0 仍会重复相同的失败，所以优化为 −1。

下标 5 前的 abcda 有边界 a，普通值为 1；P[5]='a' 与 P[1]='b' 不同，保留 1。下标 7 前的 abcdaab 有边界 ab，普通值为 2；因为 P[7]=P[2]='c'，继续借用下标 2 的失败值 0。下标 8 前的最长边界为 abc，值为 3；P[8]='a' 与 P[3]='d' 不同，保留 3。

原书正文列出 11 个值，模式实际只有 10 个字符。上表按实际十个位置逐一对应。

9.3. 图 4.12 的完整匹配（课件第 5、57 页）

主串为 abcddabcababcdaabcababcdaabcabaa，模式为 abcdaabcab。课件动画依次记录：

  1. 第 5 次比较在主串下标 4、模式下标 4 失配，nextval[4]=-1，模式起点右移 5。
  2. 第 9 次比较在主串下标 8、模式下标 3 失配，失败值 0，起点再右移 3。
  3. 第 12 次比较在主串下标 10、模式下标 2 失配，失败值 0，起点再右移 2。
  4. 起点到达 10 后连续比较 10 个字符，第 22 次比较完成匹配。

因此返回 10，朴素算法为 29 次比较。匹配循环结束时主串下标指向匹配段后一位，返回式为“结束下标减模式长度”。
