求职路线图速查

第 9 课的压缩要点。核心原则：工程能力是硬门槛，金融知识是软门槛。目标岗位 = 软件工程师 / 量化开发。

三阶段时间线

阶段重点里程碑
0–6 月Python 入门 + 数学地基（微积分/线代/概率）能用 Python 独立处理数据
6–18 月转 C++、刷 LeetCode、做 1–2 个项目medium 题稳、GitHub 有作品
3–4 年（长期）系统/性能/ML，冲实习拿到做市商实习

关键动作 Checklist

  • ☐ 完成一门编程入门（CS50 / MIT Python）
  • ☐ 数学三门：微积分、线性代数、概率统计
  • ☐ C++ 数据结构与算法 + 面向对象 + 并发
  • ☐ LeetCode 刷到 medium+
  • ☐ 1–2 个交易/低延迟主题项目放 GitHub（如订单簿模拟器、市场数据回放库、回测框架）
  • ☐ 编程竞赛 / Kaggle 攒经历
  • ☐ 冲实习（做市商实习 = 转正主路径）

资源

  • 入门：CS50（哈佛）、MIT OCW
  • 刷题：LeetCode、Kaggle
  • 量化资源库：GitHub — quant-developers-resources
  • 社区：r/quant、r/FinancialCareers、Wall Street Oasis
