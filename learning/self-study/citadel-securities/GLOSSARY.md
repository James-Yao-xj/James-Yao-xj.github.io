# 城堡证券（Citadel Securities）术语表

本工作区用于理解做市商 Citadel Securities 及其所在行业的规范用语。每个术语一经引入，后续所有 lesson 都沿用这里的定义。

## 市场基础

**股票（Stock / Share）**：
一家公司所有权的最小单位，持有一股即拥有该公司的一份权益。
_Avoid_：股份、股权（口语混用）

**交易所（Exchange）**：
集中撮合买卖双方订单的公开市场，如纽交所（NYSE）、纳斯达克（Nasdaq）。
_Avoid_：交易平台、券商

**流动性（Liquidity）**：
一项资产能被快速买卖、且不会显著影响其价格的程度。流动性好 = 随时能按接近当前价成交。
_Avoid_：变现能力

## 资产类别

**期权（Option）**：
一种"在未来某日以约定价格买入/卖出某资产"的权利（不是义务）。做市商的重要战场之一。
_Avoid_：选择权

**固定收益（Fixed Income）**：
债券等承诺定期支付固定利息的资产类别。
_Avoid_：债券（是其中主要品类，但固定收益更宽）

## 做市与价差

**做市商（Market Maker）**：
持续同时报出买入价和卖出价、承诺随时买卖、从而为市场提供流动性的机构。
_Avoid_：庄家（带贬义/误导）

**订单簿（Order Book）**：
一个市场里所有"想买"和"想卖"订单的实时排队列表。
_Avoid_：挂单表

**限价单 / 市价单（Limit Order / Market Order）**：
限价单按指定价格挂起等待成交；市价单立即按当前最好价格成交。
_Avoid_：挂单 / 直接买（口语）

**买入价 / 卖出价（Bid / Ask）**：
bid 是做市商愿意买入的价格（较低）；ask 是它愿意卖出的价格（较高）。
_Avoid_：买一价 / 卖一价（那是订单簿的深度术语）

**最好买价 / 最好卖价（Best Bid / Best Ask）**：
买盘里最高的价 / 卖盘里最低的价，二者之差即价差。

**买卖价差（Bid-Ask Spread）**：
卖出价与买入价之差，是做市商单笔交易的主要收入来源。
_Avoid_：点差（外汇语境）、差价

**中间价（Mid Price）**：
(最好买价 + 最好卖价) ÷ 2，市场对资产当前公允价的最佳估计。

**双向报价（Two-Sided Quote）**：
做市商同时在买盘和卖盘各挂一个价、随时双向成交的行为。

## 订单与客户

**订单流（Order Flow）**：
客户发来的买卖订单的集合与流向，是做市商获取交易机会的"原料"。
_Avoid_：流量、单量

**支付订单流费用（Payment for Order Flow, PFOF）**：
做市商向券商付费，以换取该券商散户客户的订单流。
_Avoid_：返佣、回扣

**最佳执行（Best Execution）**：
券商/做市商对客户负有"以最有利条件成交"的合规义务。PFOF 争议的核心。
_Avoid_：最优成交

**价格改善（Price Improvement）**：
做市商给散户提供优于公开交易所的成交价。PFOF 支持者的主要论据。

## 风险

**逆向选择（Adverse Selection）**：
做市商与信息比自己更灵通的对手成交、从而吃亏的风险（例如刚报出 $150.01 卖出，股价就跳到 $155）。
_Avoid_：被骗（口语）

**库存风险（Inventory Risk）**：
做市商因持有头寸、价格朝不利方向变动而亏损的风险。

**对冲（Hedging）**：
通过反向交易，把某类风险（如方向风险）降到最低的做法。

**Delta 对冲（Delta Hedging）**：
期权做市的核心手段：买卖标的股票以抵消期权价格随标的方向变动的风险，保持大致"方向中性"。
_Avoid_：Delta 中性（是其结果状态）

**波动率（Volatility）**：
价格波动的剧烈程度。波动越大，做市风险越高、价差往往越宽。

## 方法与技术

**量化（Quant）**：
用数学模型、统计推断和程序化手段做交易研究或交易的方法。
_Avoid_：量化交易（当形容词用）

**低延迟（Low Latency）**：
从接收行情到发出订单响应之间的时间极短，是做市商速度竞争的关键指标。
_Avoid_：快、高频（高频是低延迟的一种应用）

**高频交易（HFT, High-Frequency Trading）**：
以极高速度、极短持仓时间执行的算法交易，常借助低延迟系统。
_Avoid_：快进快出（口语）

**市场微观结构（Market Microstructure）**：
研究订单如何形成、撮合、影响价格的分支学科，做市商的核心知识域。
_Avoid_：盘口分析

**自营交易（Proprietary Trading / Prop Trading）**：
用自有资金交易获利（区别于替客户管理资金）。做市本质是自营交易的一种。
_Avoid_：自营盘
