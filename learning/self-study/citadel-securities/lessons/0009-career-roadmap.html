第 9 课 · 求职路线图

从零基础到实习/offer 的路线图

前面八课建立了认知，这一课给行动。一句话原则：工程能力是硬门槛，金融知识是软门槛。零基础最现实的目标是"软件工程师 / 量化开发"，本课就按这条主线铺路。

1 · 先认清一个现实

做市商招人不看你"懂不懂金融"——金融可以入职后学。真正筛人的是编程、数学、反应这些硬能力。多位从业者的共识是：量化开发岗本质是"带金融味道的软件工程，而不是带软件味道的金融"。所以别一上来啃金融术语，先练硬功夫。

2 · 短期（0–6 个月）：打地基

  • 编程入门：Python。用 CS50（哈佛）或 MIT 的 Python 入门课起步。
  • 数学：微积分、线性代数、概率与统计——这是后面一切的地基。
  • 目标：能独立写小程序、用 Python 处理数据。

3 · 中期（6–18 个月）：转向硬核

  • 转 C++：做市商的核心系统用 C++，把数据结构、算法、面向对象、并发练扎实。
  • 刷题：LeetCode 刷到 medium 以上，算法能力是面试硬通货。
  • 做 1–2 个项目：一个"市场数据/低延迟/交易"主题的 C++ 或 Python 项目，放进 GitHub。例如：市场数据回放库、一个简单的订单簿模拟器、一个回测框架。

4 · 长期（在校或转行 3–4 年）

阶段重点
第 1 年Python、计算机基础、微积分、统计
第 2 年C++ 面向对象、线代、概率、算法、金融市场入门
第 3 年时间序列、机器学习、随机过程、衍生品基础
第 4 年高性能计算、作品集项目、冲实习

5 · 决定成败的关键动作

  • 实习是最高杠杆：做市商的实习（约 11 周）是转正主路径，尽早冲。
  • 竞赛加分：编程竞赛（LeetCode/ACM）受自营交易公司青睐；Kaggle 练数据/建模。
  • 开源与作品：公开的 GitHub 项目是最可信的能力证明。
  • networking：去 r/quant、r/FinancialCareers、Wall Street Oasis 了解真实面经与薪资。
心态提醒

录取率低于 1%，竞争激烈是常态。但这条路不靠"懂金融"，靠的是持续把编程和数学练到够硬。你现在是零基础，意味着还有完整的可塑空间——按阶段来，别跳步。
